**Версия документации:** 1.0  
**Статус:** Концепция для представления Правительству РФ  
**Классификация:** Для служебного пользования (проектная документация)

---

## Краткое резюме

**ЕПСОК** — федеральная информационная платформа межведомственной координации, предназначенная для повышения раскрываемости преступлений, сокращения сроков расследования и обеспечения процессуальной законности при взаимодействии правоохранительных и иных государственных органов.

Платформа **не заменяет** ведомственные системы (ГИАЦ, СОДЧ, информационные системы СК РФ, ФСБ и др.), а **надстраивается** над ними через единый шлюз взаимодействия (СМЭВ) и обеспечивает:

- сквозное ведение расследований с межведомственной юрисдикцией;
- граф анализа связей между лицами, объектами и событиями;
- цифровой конвейер межведомственных запросов;
- единый реестр доказательств с неизменяемым журналом;
- федеральную аналитику модус операндi и раннего выявления серий;
- автоматический контроль процессуальных сроков по УПК РФ.
- **Horizon Intelligence** — Serendipity, Ghost Link, Investigation Digital Twin.
- **Tech Admin Console** — мониторинг, интеграции, OSINT/Horizon config (без доступа к делам).

## Ключевые показатели эффекта (целевые, к 2032 г.)

| Показатель | Базовый уровень | Целевой уровень |
|---|---|---|
| Срок межведомственного запроса | 14–45 раб. дней | 1–3 раб. дня |
| Доля дел с установленными межрегиональными связями | ~12% | ≥45% |
| Процессуальные нарушения по срокам (УПК) | ~8% дел | ≤2% |
| Время формирования оперативной картины по серийным преступлениям | 2–4 недели | 24–72 часа |
| Доля цифровых доказательств с верифицированной цепочкой custody | ~30% | ≥95% |
