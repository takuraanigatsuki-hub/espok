# ЕПСОК — MVP демо (5 минут)

## Запуск

```bash
cd demo
npx serve public -p 3000
```

Откройте [http://localhost:3000](http://localhost:3000) и обновите страницу с **Ctrl+F5**.

### E2E-тесты (Playwright)

```bash
cd demo
npm install
npx playwright install chromium
npm run test:e2e
```

Покрытие: вход/ошибка пароля, реестр → карточка дела, экспорт TXT, глобальный поиск, навигация, выход, блокировка, security headers, privacy veil.

**Адаптивность** (`e2e/responsive.spec.js`): 1440 / 1280 / 768 / 390 / 360 px + вход на 320 px — без горизонтального переполнения, мобильное меню и свёрнутый сайдбар.

Отчёт HTML: `demo/playwright-report/index.html` после прогона.

### Продакшен

- **Основной URL:** https://epsok.ru/ (редирект HTTP→HTTPS включён в ISPmanager)
- Резерв VPS: https://80.78.245.66/ (после переключения DNS A → `80.78.245.66`)

Обновление на хостинге: `FTP_PASS=… node deploy-public-ftp.mjs` (полная заливка `demo/public`) или только `.htaccess`: `node deploy-htaccess-ftp.mjs`.  
Включить редирект (если сбросится): `ISP_PASS=… node enable-hosting-https-isp.mjs`.

Обновление на VPS: `ESP_OK_DEPLOY_PASS=… node deploy-remote.mjs`  
HTTPS на VPS: смените A-записи на `80.78.245.66`, затем `node enable-https-vps.mjs`.

### Защита доступа (v2.5.0)

Контур защиты объединяет [NIST CSF 2.0](https://www.nist.gov/cyberframework) / D3FEND-практики (по [Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)) с уже внедрёнными мерами:

| Слой | Мера |
|------|------|
| **Периметр** | HTTP Basic Auth на хостинге (`.htpasswd` только на сервере, не в git) |
| **Роли** | Привязка персоны к учётке · блок эскалации в тех./функ. админ (ПОЛ-008) |
| **Транспорт** | HTTPS → полный Web Crypto (AES-GCM, HMAC, PBKDF2); HTTP — демо-fallback |
| **Заголовки** | CSP, `X-Frame-Options: DENY`, `nosniff`, COOP/CORP, `Permissions-Policy` (`.htaccess` / `serve.json`) |
| **Сессия** | Шифрованная сессия, lockout после 5 попыток, автоблокировка 15 мин, Ctrl+Shift+L |
| **XSS / инъекции** | `escapeHtml`, санитизация deep-link (`#view=…`), блок `javascript:` в `window.open` |
| **Утечки** | Privacy veil при смене вкладки; аудит копирования из `data-confidential` |
| **Аудит** | WORM-журнал, «Мои действия» (CSV), диагностика без токенов |

- **Быстрая блокировка**: меню профиля → «Заблокировать» или **Ctrl+Shift+L** (запись в журнал аудита).
- **Автоблокировка**: 15 мин бездействия; предупреждение за 60 с; индикатор ⏱ в шапке.
- **Мои действия**: меню профиля → экспорт личного журнала (CSV, ПОЛ-005).
- **Журнал аудита (CSV)**: только **тех. админ** (`sidorov.av`) — меню профиля и ЦОД.
- **Горячие клавиши**: **?** — шпаргалка; **Ctrl+K** / **/** — поиск; **g**+буква — навигация.
- **Диагностика**: Справка → «Собрать диагностику» — JSON в буфер и в текст обращения (без паролей и токенов).

## Сценарий 1 — Следователь (ivanov.sp)

### 1. Дело и справка

1. Войти как `ivanov.sp`
2. **Реестр дел** → открыть `ЕПСОК-2028-004521`
3. **Справка по делу (TXT)** → файл `EPSOK-2028-004521-spravka.txt` в «Загрузки»

### 2. Межведомственный запрос

1. **Запросы** → **Создать запрос**
2. Уровень: **Межвед** · ведомство **ФНС** · тип «2-НДФЛ»
3. Указать правовое основание (постановление) → **Отправить**
4. Переключить роль (Демо) → **Исполнитель ФНС** (`EXEC_FNS` в списке ФНС)
5. На дашборде исполнителя — принять запрос → **Предоставить результат** (текст выписки)
6. Вернуться к **Иванову** → **Запросы** → открыть результат → **Скачать TXT**

### 3. Заявка на доступ (Горизонт)

1. Под **Ивановым**: в меню нет «Горизонт» → **Запросить доступ** (внизу меню или из уведомления)
2. Модуль: **Горизонт** · основание: связь с делом / постановление
3. Переключить роль → **Морозова Е.А.** (руководитель МВД)
4. **Сотрудники** → вкладка **Кадры** → блок **Заявки на доступ (ПОЛ-011)** → **Да**
5. Вернуться к **Иванову** (Демо) → в меню появится **Горизонт** · проверить **Почту**

### 4. Регламенты

1. **Регламенты** → вкладка **Политики**
2. Прочитать вступление: что такое **ПОЛ**
3. Нажать карточку (например **ПОЛ-001**) → модалка «Что можно / Что нельзя»

## Что работает в MVP

- Реестр дел, карточка, рабочая группа (**Изменить состав**)
- **Почему нет доступа** — панель с фактами, ПОЛ, что можно / нельзя
- **Цепочка происхождения** — откуда в деле появились сведения
- Выгрузка справки и **пакета для надзора/суда** (TXT)
- Запросы: создание → **симуляция IDT-lite** → исполнение → скачивание
- **Горизонт → черновик запроса** (кнопки SE / PRO / GLD открывают форму с подстановкой)
- **Provenance → граф** (кнопка «На графе» подсвечивает узлы)
- **Слепой контур исполнителя** (EXEC_FNS не видит номер дела и ФИО)
- **Коллизия параллельных расследований** в Горизонте (согласование РГ)
- Заявки на расширение доступа и согласование руководителем
- Политики ПОЛ: понятные карточки + детализация по клику
- Скрытие технических меток от следователей
- Справка: подсветка раздела при прокрутке
