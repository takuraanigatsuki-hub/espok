Справка по работе с ЕПСОК

Руководство пользователя · пилотный регион · версия интерфейса 1.9.2

Начало работы

  1. Войдите под учётной записью, выданной управлением ИТ ведомства. Контур (следственный / тех.) определяется ролью.
  2. В демо-режиме бейдж Демо внизу меню открывает выбор роли по всем ведомствам каталога.
  3. На дашборде — сводка по делам, срокам, межведомственным запросам и сигналам «Горизонт».
  4. Откройте реестр дел — фильтр по региону, отделу и ведомству.
  5. Откройте карточку дела для хронологии, участников и смежных дел.
  6. Создавайте запросы данных — межведомственные (СМЭВ), внутри ведомства (ГИАЦ, ЦЭК) или внутри отдела (ОУР, руководитель) — только с правовым основанием.
  7. Все действия фиксируются в журнале аудита (неизменяемая запись).
Важно: массовый просмотр персональных данных запрещён (ПОЛ-005). При превышении лимита сессия блокируется.

Защита сессии

  • Блокировка — меню пользователя → «Заблокировать» или Ctrl+Shift+L. Сессия очищается, экран входа возвращается без выхода из внешнего шлюза хостинга.
  • Автоблокировка — через 15 минут бездействия; предупреждение за 60 секунд. Индикатор ⏱ в шапке показывает оставшееся время.
  • Журнал аудита — блокировка, автоблокировка и выход фиксируются с пометкой ПОЛ-005 (тех. админ → ЦОД → журнал).
  • Диагностика — раздел «Поддержка» → «Собрать диагностику»: снимок окружения без паролей для обращения в ЦОД.

Открытые источники

Перед запуском проверки укажите:

  • тип и значение цели (почта, телефон, никнейм, ФИО, домен);
  • профиль модулей (пассивный / расширенный / углублённый);
  • правовое основание — постановление или поручение (ПОЛ-006).

Результаты не заменяют официальный запрос в ГИАЦ, ИБД или банк данных МВД. Исполнительный сервис работает в изолированном контуре.

Горизонт

Горизонт — федеральный аналитический слой ЕПСОК для поиска совпадений и скрытых связей между делами без единой гражданской базы данных. Система сравнивает обезличенные паттерны (хеши телефонов, счетов, ФИО и др.) только по активным делам в пилотных регионах. Раскрытие персональных данных — только через межведомственный запрос с правовым основанием (ПОЛ-007).

Модуль доступен из бокового меню Аналитика → Горизонт, с дашборда и карточки дела (для дел с кластером или смежными делами). Выберите дело, откройте нужный аналитический модуль и запустите анализ.

  • Сигналы и совпадения отображаются в ленте оповещений; из рекомендаций можно сразу создать черновик межвед. запроса.
  • Модуль не заменяет ГИАЦ, ИБД и официальные ведомственные базы — формирует гипотезы для следователя.
  • Доступ: руководитель СО, прокурор, следователь СК, аналитик (пилотные регионы — Краснодарский край, Москва, Татарстан).
Важно: раскрытие данных смежного дела требует согласования рабочих групп или прокурорского акта. Все действия фиксируются в журнале аудита.

Частые вопросы

Почему не отправляется запрос?
Проверьте уровень (межвед / ведомство / отдел), правовое основание и полномочия (вкладка «Ведомства»).
Не вижу модуль «Горизонт»
Модуль включён для пилотных регионов. Обратитесь к ответственному за регион по ПОЛ-014.
Как сменить роль в демо?
Бейдж Демо внизу бокового меню — выбор персоны по всем ведомствам (руководитель / подчинённый). В продуктиве роль назначает управление ИТ.

Политики доступа

ПОЛ — политика доступа ЕПСОК: правило «кто что может делать» в системе. Код (например, ПОЛ-001) указывается в журнале аудита и уведомлениях. Нажмите на карточку — откроется пояснение простым языком.

Важно: в демо переключение ролей имитирует разные контуры. В продуктиве политики применяются автоматически по учётной записи.
