# Функции ведомств в ЕПСОК на основе ФЗ

**Версия:** 1.0  
**Реестр:** [configs/agency-registry.yaml](../../configs/agency-registry.yaml)  
**Принцип:** каждая функция платформы привязана к **конкретному ФЗ/статье УПК** и роли; без правового основания запрос не создаётся.

---

## 1. Методология

| Уровень | Описание |
|---------|----------|
| **Норма** | ФЗ / УПК / КоАП — источник полномочия |
| **Данные** | Какие сведения ведомство вправе выдавать или получать |
| **Функция EPSOK** | Модуль платформы, тип межвед-запроса, автоматизация |
| **Ограничение** | Контур (следственный / оперативный / надзорный), ABAC |

ЕПСОК **не расширяет** полномочия ведомств — только **формализует и ускоряет** уже законные процедуры.

## 2. МВД России

### Нормативная база

| Норма | Содержание |
|-------|------------|
| **3-ФЗ** «О полиции» | Функции полиции: защита прав, профилактика, раскрытие, дознание (ст. 2, 12) |
| **144-ФЗ** «Об ОРД» | Оперативно-розыскная деятельность (контур OPS) |
| **УПК РФ** ст. 40, 41, 144–145 | Дознание, регистрация сообщений о преступлениях |
| **210-ФЗ** | Разграничение с ФСБ |
| **152-ФЗ** | Обработка ПДн в ГИАЦ / ИБД |

### Данные и системы

- **ГИАЦ** — учёт граждан, регистрация, документы
- **ИБД-Р** — розыск, учёт преступлений
- **ГИБДД** — транспорт, водители
- **ОРД** — оперативные материалы (отдельный контур)

### Функции ЕПСОК

| ID | Функция | Правовое основание | Роль |
|----|---------|-------------------|------|
| MVD-01 | Проверка лица по ГИАЦ | ст. 13 3-ФЗ, запрос в рамках дела ст. 183 УПК | INV, OPS* |
| MVD-02 | Розыск / ориентировка | ст. 12 3-ФЗ, ИБД | INV, OPS |
| MVD-03 | Данные ТС / ГИБДД | ст. 12 3-ФЗ | INV |
| MVD-04 | CDR / связь (по постановлению) | ст. 186 УПК | INV |
| MVD-05 | Регистрация сообщения о преступлении | ст. 144–145 УПК | INV |
| MVD-06 | Передача дела по подследственности | ст. 151 УПК | INV_LEAD |
| MVD-07 | Оперативная разработка (контур) | 144-ФЗ, номер ОРД | OPS |
| MVD-08 | Исполнение входящих запросов других ОР | УПК, 3-ФЗ | EXEC |

\* OPS — только оперативный контур с номером ОРД.
