# Экономическое обоснование ЕПСОК

## 1. Резюме для принятия решения

**ЕПСОК** — инвестиция в федеральную инфраструктуру с расчётным **сроком окупаемости 6–8 лет** и **NPV (10 лет, ставка 8%) ≈ 45–60 млрд ₽** за счёт:

- сокращения дублирующей работы ведомств;
- ускорения раскрытия экономически значимых преступлений;
- снижения процессуальных отмен и повторных расследований;
- экономии на бумажном документообороте и командировках.

**Совокупный бюджет программы (2026–2035):** ~39 млрд ₽ (CAPEX + OPEX).

## 3. Эффекты (количественная оценка)

### 3.1. Прямые экономические эффекты

| Эффект | Механизм | Оценка, млн ₽/год (при зрелости) |
|---|---|---:|
| Сокращение бумажного МВ | Цифровые запросы вместо писем | 2 400 |
| Сокращение командировок | Удалённая координация дел | 1 800 |
| Снижение повторных расследований | Меньше отмен по процессуальным нарушениям | 3 200 |
| Экономия рабочего времени следователя | −15% на рутину (запросы, поиск связей) | 8 500 |
| **Итого прямой эффект** | | **~15 900** |

*База расчёта: ~45 000 следователей/дознавателей, средняя полная стоимость рабочего дня ~4 200 ₽.*

### 3.2. Косвенные эффекты (социально-экономические)

| Эффект | Оценка |
|---|---|
| Возврат похищенного / предотвращённый ущерб (мошенничество, экономика) | 15–40 млрд ₽/год (консерв.) |
| Снижение нагрузки на суды (меньше отмен) | 1,2 млн ₽/год на одну отмену × сокращение |
| Доверие бизнеса и граждан | Не monetized, стратегический эффект |

### 3.3. Рост раскрываемости

Консервативный сценарий: **+5% раскрываемости** по тяжким и особо тяжким преступлениям к 2032 г.

При ~220 000 таких дел в год и среднем ущербе 500 000 ₽ на нераскрытое дело — потенциал возврата/предотвращения: **5,5 млрд ₽/год**.

## 4. Сравнение с альтернативами

| Альтернатива | Плюсы | Минусы |
|---|---|---|
| **Статус-кво** (разрозненные ИС) | Нет затрат | Рост преступности, медленное раскрытие |
| **Доработка только ГИАЦ** | Уже есть | Не решает межвед, СК, ФНС |
| **Закупка зарубежной платформы** | Быстрый старт | Несуверенность, санкции, 152-ФЗ |
| **ЕПСОК (федерация)** | Межвед, суверенность, масштаб | Высокие начальные инвестиции |

**Вывод:** ЕПСОК — единственный вариант, закрывающий межведомственную координацию при суверенности данных.

## 6. Источники финансирования

1. **Федеральный бюджет** — основной источник (федеральный проект «Цифровое государственное управление»).
2. **Бюджеты ведомств** — софинансирование интеграции (МВД, СК, ФНС).
3. **ГЧП** — возможно для ЦОД и каналов связи (с ограничениями по 152-ФЗ).
4. **Гранты на R&D** — Фонд содействия инновациям (пилотные ML-модули).
