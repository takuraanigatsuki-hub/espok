# Дизайн демо EPSOK

Единая тема на базе [Government UI Kit (gov.design)](https://www.figma.com/community/file/946012832497155929/government-ui-kit-gov-design) (Figma duplicate: `fuQJa9MAO3InGltZaXWeLp`).

## Принципы

- **Один интерфейс** — без переключателя тем Cardbox / gov.design
- **Сайдбар** — тёмная навигация `#001126`, логотип и меню
- **Контент** — светлая рабочая область `#F5F5F7`, карточки с тенью gov.design
- **Шрифт** — Golos Text
- **Акцент** — `#0061D9`, ссылки `#0050B2`

## Структура

| Зона | Назначение |
|------|------------|
| Сайдбар | Навигация по разделам (Обзор · Следствие · Межвед · Аналитика) |
| Шапка контента | Заголовок страницы + статус системы |
| Подвал сайдбара | Пользователь, демо-переключатель роли, справка |

## Файлы

- `demo/public/styles.css` — все стили и токены
- `demo/public/index.html` — разметка

## Запуск

```powershell
cd demo
npx --yes serve public -p 3000
```
