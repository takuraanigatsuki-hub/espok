# Референсы дизайна госструктур для ЕПСОК

## Источники

| Ресурс | Что берём |
|--------|-----------|
| [Госуслуги](https://www.gosuslugi.ru) | Светлый фон, синий #0D4CD3, карточки, иерархия |
| [Cardbox / Cardbox ARM](https://www.gosuslugi.ru) (Минцифры) | UI-kit АРМ для госслужащих |
| [Методрекомендации Минцифры 2022](https://habr.com/ru/companies/rtlabs/articles/723974/) | Единый UX экосистемы Госуслуг |
| МВД, СК, прокуратура (публичные сайты) | Синяя шапка, трикolor-полоска, официальная типографика |

## Принципы (применены в демо)

1. **Светлая рабочая область** — снижение нагрузки при длительной работе (АРМ следователя).
2. **Фирменный синий** `#0D4CD3` — как на Госуслугах и ведомственных порталах.
3. **Трикolor** — тонкая полоска белый · синий · красный в шапке (гос. символика).
4. **Карточки с тенью** — белые панели на сером `#EEF2F6`, без «киберпанк»-тёмной темы.
5. **Чёткая типографика** — Lato / Segoe UI, заголовки 600–700, muted `#667685`.
6. **Таблицы** — полосатые строки, синий header row (как на сайтах ведомств).
7. **Статусы** — приглушённые badge (success/warning/danger), не неон.

## Отличие ЕПСОК от публичных госуслуг

- Контур **служебный** (не citizen-facing).
- Дополнительные модули (OSINT, Horizon) — акцентные, но в рамках общей палитры.
- Бейдж **ДЕМО · ПРОТОТИП** сохранён для презентаций.
