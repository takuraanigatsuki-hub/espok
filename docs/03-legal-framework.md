## 2. Правовые основания доступа к данным

Доступ пользователя к информации в ЕПСОК возможен **только** при наличии одного или нескольких оснований:

1. **Ведение уголовного дела** — пользователь назначен следователем / дознавателем / в рабочей группе.
2. **Прокурорский надзор** — прокурор в пределах надзорных полномочий.
3. **Оперативно-розыскная деятельность** — в рамках ОРД, отдельный контур.
4. **Исполнение межведомственного запроса** — сотрудник ведомства-исполнителя видит только запрошенный срез.
5. **Судебное решение** — доступ по определению суда.
6. **Аналитический контур** — только обезличенные агрегаты, без ПДн.

**Запрещено:** массовый просмотр данных без привязки к делу или ОРД.

## 3. Разделение контуров доступа

```
┌─────────────────────────────────────────────────────────────┐
│ КОНТУР          │ ПРАВОВОЙ РЕЖИМ           │ КТО ИМЕЕТ ДОСТУП │
├─────────────────┼──────────────────────────┼──────────────────┤
│ Следственный    │ ст. 183 УПК, ПДн        │ Следователь, СК,   │
│                 │                          │ МВД (по делу)      │
├─────────────────┼──────────────────────────┼──────────────────┤
│ Оперативный     │ 144-ФЗ, режим секретности│ ОВД, ФСБ (ОРД)   │
├─────────────────┼──────────────────────────┼──────────────────┤
│ Надзорный       │ Закон о прокуратуре     │ Прокурор           │
├─────────────────┼──────────────────────────┼──────────────────┤
│ Исполнительный  │ Ответ на запрос по делу │ ФНС, РФМ, ФТС...  │
├─────────────────┼──────────────────────────┼──────────────────┤
│ Аналитический   │ Обезличивание, 152-ФЗ   │ Аналитики,         │
│                 │                          │ руководство        │
└─────────────────┴──────────────────────────┴──────────────────┘
```

Передача данных из оперативного контура в следственный — **только** при наличии процессуального основания (ст. 89 УПК и др.).

## 4. Требования к документам для внедрения

Для включения в государственную программу необходимо подготовить:

### 4.1. Нормативные акты (предлагаемые)

1. **Распоряжение Правительства РФ** — о создании межведомственной рабочей группы и утверждении концепции.
2. **Постановление Правительства РФ** — о федеральной государственной информационной системе «ЕПСОК» (ФГИС).
3. **Приказ Минцифры** — о подключении к СМЭВ, регламент обмена.
4. **Соглашения между ведомствами** — о порядке доступа и SLA (МВД, СК, ФСБ, ФНС, РФМ, ФТС, Генпрокуратура).
5. **Методические рекомендации** — для следователей и оперативников по работе в ЕПСОК.

### 4.2. Экспертные заключения

- ФСТЭК — класс защищённости ИС и ИСПДн.
- ФСБ — при использовании СКЗИ и грифованных данных.
- Минюст — правовая экспертиза регламентов.
- Генпрокуратура — согласование надзорного контура.

---

## 5. Ответственность и аудит

- Каждое действие пользователя фиксируется в WORM-журнале.
- Несанкционированный доступ — дисциплинарная, административная (ст. 13.11, 13.14 КоАП), уголовная (ст. 137, 272, 274.1 УК) ответственность.
- Прокуратура получает инструмент надзора за соблюдением порядка доступа.
- Внутренние проверки ведомств — отчёты по аномальной активности (массовый экспорт, ночные сессии и т.д.).

---

## 6. Соответствие международным обязательствам

ЕПСОК не предполагает трансграничной передачи персональных данных. Обработка — исключительно на территории РФ. При необходимости правовой помощи по международным делам — отдельный модуль с правовыми основаниями (MLAT, запросы через Генпрокуратуру).

---

## 7. Защита прав граждан

- Граждане **не являются** пользователями ЕПСОК.
- Право на доступ к своим ПДн — через установленные каналы (152-ФЗ), не через платформу.
- Обезличивание в аналитическом контуре — необратимое хеширование идентификаторов.
- Срок хранения — в соответствии с УПК и ведомственными регламентами; автоматическое архивирование.
