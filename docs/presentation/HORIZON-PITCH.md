## Три «вау»-эффекта для демо

### 1. Serendipity Alert (Серендипity)

> «В 03:14 платформа обнаружила: SIM из вашего дела фигурирует в деле ЕПСОК-2028-001234 (Москва, 159.3 УК). Рабочая группа уведомлена.»

Подозреваемый найден **через пересечение**, а не через месяц переписки.

### 2. Ghost Link

> «Подозреваемый А не связан с IBAN жертвы напрямую. Обнаружен путь: А → ООО «Номинал» → бухгалтер B → IBAN. Рекомендуем запрос ФНС по ООО.»

### 3. Investigation Twin

> «Если запросить CDR сейчас — +12 узлов, SLA 4 ч, срок следствия −3 дня риска. Альтернатива: запрос РФМ (1,5 дня, +8 узлов, меньший риск срока).»

## Правовая рамка (для прокуратуры)

- Доступ только по **открытому делу** и **основанию**.
- Федеральный индекс — **хеши**, не ФИО.
- Раскрытие смежного дела — **согласование** или прокурор.
- Каждая гипотеза → **EvidenceItem** или межвед запрос для подтверждения.
