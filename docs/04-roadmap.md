# Дорожная карта внедрения ЕПСОК

## Общие параметры

| Параметр | Значение |
|---|---|
| Общий горизонт | 2026–2035 (10 лет) |
| Модель внедрения | Поэтапная, пилот → регионы → федерация |
| Заказчик (предлагаемый) | Межведомственная комиссия при Правительстве РФ |
| Оператор платформы | Минцифры России (техн.) + МВД (метод.) |
| Бюджет (оценка) | см. [05-business-case.md](05-business-case.md) |

---

## Фаза 0: Подготовка (2026, 12 месяцев)

### Цели
- Утверждение концепции на уровне Правительства.
- Создание межведомственной рабочей группы.
- Правовая экспертиза и проект нормативных актов.

### Результаты
- [ ] Распоряжение Правительства о концепции ЕПСОК
- [ ] Межведомственные соглашения (draft) — МВД, СК, Генпрокуратура
- [ ] Техническое задание на пилот
- [ ] Выбор 3 пилотных регионов (рекомендация: Москва, Татарстан, Краснодарский край — разная нагрузка и зрелость ИТ)
- [ ] Предпроектное обследование ведомственных ИС

### Бюджет фазы: ~180 млн ₽ (экспертиза, ТЗ, управление программой)

---

## Фаза 1: Пилот (2027–2028, 24 месяца)

### Участники
МВД, СК РФ, Генпрокуратура — в 3 регионах.

### Функционал MVP
1. Единая карточка расследования
2. Контроль процессуальных сроков (Deadline Engine)
3. Межведомственные запросы: МВД ↔ СК ↔ Прокуратура
4. Журнал аудита (WORM)
5. Базовый граф связей (Person, Phone, Case)
6. Web-интерфейс для следователя и руководителя
7. **Tech Admin Console** (SVC, USR, INT, CFG) — отдельный admin host, POL-008

### KPI пилота
| KPI | Целевое значение |
|---|---|
| Активных пользователей | ≥ 500 |
| Дел в системе | ≥ 5 000 |
| Средний срок межвед запроса | ≤ 5 раб. дней |
| Удовлетворённость пользователей | ≥ 70% |
| Процессуальных нарушений по срокам | −30% vs контрольная группа |
| Uptime платформы | ≥ 99.5% |

### Бюджет фазы: ~2,8 млрд ₽ (разработка, ЦОД пилота, обучение)

---

## Фаза 2: Региональное масштабирование (2029–2030)

### Участники
+ ФНС, Росфинмониторинг, ФТС, Росгвардия — все субъекты РФ (по 8–10 федеральным округам).

### Новый функционал
1. Interagency Request Hub — полный набор типов запросов
2. Evidence Registry (цифровые и физические доказательства)
3. Расширенный граф (счета, юрлица, транспорт, таможня)
4. **OSINT Intelligence Service** — контролируемый сбор из открытых источников (SpiderFoot Worker)
5. **Tech Admin Console** — OSW, HZM, OPS (purge, maintenance windows)
6. MO-аналитика (кластеризация)
7. Мобильный клиент (ограниченный — полевые задачи)
8. Интеграция с СОДЧ (112/102) — ранние сигналы

### KPI
| KPI | Целевое значение |
|---|---|
| Регионов | 85 субъектов |
| Пользователей | ≥ 30 000 |
| Межвед запросов/год | ≥ 500 000 |
| SLA исполнения запросов | ≤ 3 раб. дня (80%+) |

### Бюджет фазы: ~12 млрд ₽

---

## Фаза 3: Федеральная платформа (2031–2032)

### Участники
+ ФСБ (ограниченный контур), ФСИН, суды (read-only для процессуальной проверки), ЦБ (115-ФЗ).

### Новый функционал
1. Координационные центры особо важных дел
2. **Horizon Intelligence Layer** — Serendipity, Ghost Link, MO Resonance, Investigation Digital Twin
3. Предиктивная аналитика (anomaly detection по СОДЧ)
4. NLP-извлечение сущностей из протоколов
5. Федеральный дашборд для руководства
6. Полная интеграция с ГосСОПКА

### KPI
| KPI | Целевое значение |
|---|---|
| Пользователей | ≥ 100 000 |
| Дел/год | ≥ 1 500 000 |
| Доля дел с выявленными связями | ≥ 40% |
| Рост раскрываемости (тяжкие/особо тяжкие) | +8–12% vs 2026 |

### Бюджет фазы: ~18 млрд ₽

---

## Фаза 4: Зрелость и оптимизация (2033–2035)

### Задачи
- AI-ассистент следователя (on-premise LLM, объяснимые рекомендации)
- Международный модуль правовой помощи
- Автоматизация типовых процессуальных документов
- Непрерывная сертификация и аудит ФСТЭК/ФСБ
- Передача на полное операционное сопровождение

### Бюджет фазы: ~6 млрд ₽ (эксплуатация + развитие)

## Риски и меры mitigation

| Риск | Вероятность | Меры |
|---|---|---|
| Межведомственное сопротивление | Высокая | Соглашения на уровне министров, KPI для ведомств |
| Устаревшие ИС ведомств | Высокая | Адаптеры, поэтапная интеграция, не big bang |
| Утечка данных | Средняя | WORM-аудит, ABAC, ГосСОПКА, red team |
| Срыв сроков пилота | Средняя | Agile, MVP-first, 3 региона с разной сложностью |
| Нехватка кадров | Высокая | Центры обучения, сертификация пользователей |
| Изменение законодательства | Средняя | Модульная архитектура, конфигурируемые правила |
